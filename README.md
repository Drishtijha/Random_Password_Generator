## 🌸 About This Project

Hi! I'm **Drishti** 💕

This is my Random Password Generator project, created as part of my journey into web development. I built it to practise HTML, CSS, and JavaScript while making something useful and easy to use.

The website lets users choose a password length and select the types of characters they want to include.

## 🎀 Features

- 🔢 Choose a password length from **4 to 32 characters**
- 🔠 Include uppercase letters (`A–Z`)
- 🔡 Include lowercase letters (`a–z`)
- 🔢 Include numbers (`0–9`)
- ✨ Include special symbols
- 📋 Copy a generated password with one click
- 💪 View an estimated password-strength indicator
- 📱 Responsive, dark-themed interface

## 🚀 How to Use

1. Open the [live website](https://drishtijha.github.io/Random_Password_Generator/).
2. Choose your preferred password length.
3. Select the character types you want to include.
4. Click **Generate Password**.
5. Click **Copy** to copy your password.
